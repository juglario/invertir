# Invertir desde cero

Un sitio para empezar a invertir desde cero, en español: la inflación, el colchón, el interés compuesto, los índices y cómo repartir la plata. Incluye guías para lectores específicos (`empezar.html`, para quien cobra un sueldo y quiere ordenarse).

Sitio estático, sin dependencias, sin cookies ni seguimiento. El progreso se guarda solo en tu navegador.

Educación financiera, no asesoramiento personalizado.
